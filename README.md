# Star Catch — the agent builds a game from one prompt

A 12-second vertical video for the [make.fun post-x bounty](https://make.fun/c/post-x-the-agent-builds-a-game-from-20261122-1709): my AI agent takes one prompt — *"Build me a tiny game: catch the falling stars, 30 seconds, score counter."* — and builds **Star Catch**, a portrait HTML5 canvas game where you catch falling stars with a basket for 30 seconds while the score ticks up.

The clip shows the hook first (the finished game running, stars being caught), then the prompt on screen, then the agent working, then the game running again, and ends on make.fun's referral end card with the account's referral code.
